# WorkoutCrew 도메인 모델

## 1. User

### 의미
- WorkoutCrew 서비스를 이용하는 회원을 나타낸다.

### 상태
- `id: Long`
    - 사용자를 식별하기 위한 고유 식별자

- `email: String`
    - 이메일 형식이어야 한다.
    - 다른 사용자와 중복될 수 없다.

- `password: String`
    - 사용자가 입력한 원문 비밀번호를 단방향 해시한 값을 저장한다.
    - 원문 비밀번호는 저장하지 않는다.
    - 회원가입 입력 비밀번호는 해시 변환 전에 최소 8자 이상이어야 한다.
    - 회원가입 입력 비밀번호는 해시 변환 전에 최대 20자 이하이어야 한다.
    - 저장 공간은 선택한 단방향 해시 결과의 전체 길이를 수용해야 한다.

- `nickname: String`
    - 최소 2자 이상이어야 한다.
    - 최대 10자 이하이어야 한다.
    - 다른 사용자와 중복될 수 없다.


## 2. Crew

### 의미
- 사용자들이 함께 운동 활동을 수행하는 운동 크루를 나타낸다.

### 상태
- `id: Long`
    - 크루를 식별하기 위한 고유 식별자

- `name: String`
    - 최소 2자 이상이어야 한다.
    - 최대 20자 이하이어야 한다.
    - 다른 크루와 중복될 수 없다.

- `password: String`
    - 최소 4자 이상이어야 한다.
    - 최대 8자 이하이어야 한다.

- `maxUsers: int`
    - 크루에 가입할 수 있는 최대 인원 수를 의미한다.
    - 최소 2명 이상이어야 한다.
    - 최대 100명 이하이어야 한다.

- `weeklyCertificationGoal: int`
    - 크루의 주간 목표 운동 인증 횟수를 의미한다.
    - 최소 1회 이상이어야 한다.
    - 최대 7회 이하이어야 한다.


## 3. CrewUser

### 의미
- User와 Crew 사이의 소속 관계를 나타낸다.
- 특정 사용자가 어떤 크루에 속해 있으며, 해당 크루에서 어떤 역할을 가지는지 표현한다.

### 상태
- `id: Long`
    - CrewUser 관계를 식별하기 위한 고유 식별자

- `user: User`
    - 크루에 소속된 사용자를 의미한다.

- `crew: Crew`
    - 사용자가 소속된 크루를 의미한다.

- `role: CrewRole`
    - 사용자가 해당 크루에서 가지는 역할을 의미한다.
    - `MEMBER`: 일반 크루원
    - `MANAGER`: 크루 관리자


## 4. 도메인 관계

User 1 ---- N CrewUser N ---- 1 Crew

- 하나의 User는 여러 Crew에 가입할 수 있다.
- 하나의 Crew에는 여러 User가 가입할 수 있다.
- User와 Crew의 N:M 관계를 CrewUser가 표현한다.


## 5. 핵심 도메인 규칙

### User
- 이메일은 중복될 수 없다.
- 닉네임은 중복될 수 없다.
- 이메일은 올바른 형식이어야 한다.
- 회원가입 입력 비밀번호는 해시 변환 전에 8자 이상 20자 이하이다.
- 비밀번호는 원문을 저장하지 않고 단방향 해시한 값을 저장한다.
- 닉네임은 2자 이상 10자 이하이다.

### Crew
- 크루 이름은 중복될 수 없다.
- 크루 이름은 2자 이상 20자 이하이다.
- 크루 비밀번호는 4자 이상 8자 이하이다.
- 최대 인원은 2명 이상 100명 이하이다.
- 주간 목표 운동 인증 횟수는 1회 이상 7회 이하이다.

### CrewUser
- 동일한 User와 Crew의 소속 관계는 중복될 수 없다.
- 역할은 MEMBER 또는 MANAGER이다.
- 한 크루에는 MANAGER 역할을 가진 크루원이 한 명 존재한다.
- MANAGER는 반드시 해당 크루에 소속된 User여야 한다.
