# 문제 정의

아주대학교 학생지원팀에서는 학생들이 직접 운동 프로그램을 설계하고 운영할 수 있도록 운동크루 모집 프로그램을 지원하고 있다.

해당 프로그램에 직접 참여하면서, 운동크루의 지속적인 운영이 크루 관리자 개인의 노력에 크게 의존하고 있다는 문제를 발견했다.

관리자가 적극적으로 일정 관리, 참여자 관리, 운동 인증 확인, 공지 및 참여 독려 등의 업무를 수행하는 경우에는 크루 활동이 비교적 안정적으로 유지되지만, 관리자의 개입이 줄어들 경우 활동이 쉽게 중단되거나 참여율이 감소하는 문제가 발생한다.

또한 이러한 운영 업무가 관리자 한 명에게 집중되면서 관리자가 반복적인 관리 업무에 피로를 느끼게 되고, 장기적으로 크루 운영을 지속하기 어려워지는 문제가 있다.

참여자 입장에서도 운동 인증과 활동 기록이 크루별 게시글이나 메시지 형태로 흩어져 있어, 자신이 언제 어떤 운동을 했는지 한눈에 확인하거나 이전 활동을 지속적으로 관리하기 어렵다는 문제가 있다. 이로 인해 운동크루 활동이 개인의 지속적인 운동 기록으로 이어지기 보다는 일회성 인증에 그치는 경우가 발생한다.

따라서 운영에 필요한 반복적인 관리 업무를 줄이고, 특정 관리자 개인의 노력에 지나치게 의존하지 않으면서도 운동크루가 지속적으로 운영될 수 있도록 하는 동시에, 참여자가 자신의 운동 활동을 체계적으로 기록하고 확인할 수 있는 방법이 필요하다.
