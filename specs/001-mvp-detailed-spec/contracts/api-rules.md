# WorkoutCrew MVP API 세부 규칙

이 문서는 WorkoutCrew MVP REST 인터페이스의 메서드, 경로, 메시지, 오류, 인증, 목록 규칙을
정의하는 기준 계약이다.

## 1. 성공 계약

| 기능 | 메서드와 경로 | 상태 | message | data |
|------|---------------|------|---------|------|
| CSRF 토큰 조회 | `GET /api/v1/auth/csrf` | 200 | `CSRF 토큰을 조회했습니다.` | 토큰 정보 |
| 회원가입 | `POST /api/v1/users` | 201 | `회원가입이 완료되었습니다.` | null |
| 로그인 | `POST /api/v1/auth/login` | 200 | `로그인이 완료되었습니다.` | null |
| 로그아웃 | `POST /api/v1/auth/logout` | 200 | `로그아웃이 완료되었습니다.` | null |
| 닉네임 수정 | `PATCH /api/v1/users/me` | 200 | `닉네임이 수정되었습니다.` | null |
| 회원탈퇴 | `DELETE /api/v1/users/me` | 200 | `회원탈퇴가 완료되었습니다.` | null |
| 크루 생성 | `POST /api/v1/crews` | 201 | `크루가 생성되었습니다.` | null |
| 크루 목록 조회 | `GET /api/v1/crews` | 200 | `크루 목록을 조회했습니다.` | 크루 페이지 |
| 크루 정보 수정 | `PATCH /api/v1/crews/{crewId}` | 200 | `크루 정보가 수정되었습니다.` | null |
| 크루 삭제 | `DELETE /api/v1/crews/{crewId}` | 200 | `크루가 삭제되었습니다.` | null |
| 크루 가입 | `POST /api/v1/crews/{crewId}/members` | 201 | `크루에 가입했습니다.` | null |
| 크루 탈퇴 | `DELETE /api/v1/crews/{crewId}/members/me` | 200 | `크루에서 탈퇴했습니다.` | null |
| 관리자 위임 | `PATCH /api/v1/crews/{crewId}/manager` | 200 | `관리자 권한이 위임되었습니다.` | null |
| 크루원 목록 조회 | `GET /api/v1/crews/{crewId}/members` | 200 | `크루원 목록을 조회했습니다.` | 크루원 페이지 |
| 크루원 추방 | `DELETE /api/v1/crews/{crewId}/members/{userId}` | 200 | `크루원이 추방되었습니다.` | null |

생성 성공은 `Location` 헤더로 생성 자원의 식별 URI를 제공한다. 공통 응답 본문을 유지해야
하므로 PATCH와 DELETE 성공에 204를 사용하지 않는다.

## 2. 공통 응답

모든 응답의 최상위 필드는 다음 네 개뿐이다.

```json
{
  "status": 200,
  "message": "처리 결과 설명",
  "data": null,
  "timestamp": "2026-08-23T14:05:09"
}
```

- `status`: 실제 HTTP 상태와 같은 숫자
- `message`: 위 성공 메시지 또는 아래 오류 메시지
- `data`: GET 성공만 조회값을 사용하고 변경 성공과 모든 오류는 null
- `timestamp`: `Asia/Seoul` 기준 `YYYY-MM-DDThh:mm:ss`
- 필드별 검증 상세 배열 등 추가 최상위 필드는 사용하지 않는다.

## 3. 오류 계약

| 상황 | 상태 | 대표 message |
|------|------|--------------|
| JSON 구조 오류, 필수값 누락, 형식·길이·범위 위반 | 400 | `요청 값이 올바르지 않습니다.` |
| 로그인 실패, 인증 세션 없음 또는 만료 | 401 | `인증이 필요합니다.` |
| 소속·역할 권한 부족 | 403 | `요청을 수행할 권한이 없습니다.` |
| CSRF 토큰 누락 또는 불일치 | 403 | `요청을 수행할 권한이 없습니다.` |
| 잘못된 크루 비밀번호 | 403 | `크루에 가입할 수 없습니다.` |
| 사용자, 크루 또는 소속 관계 없음 | 404 | `요청한 대상을 찾을 수 없습니다.` |
| 이메일·닉네임·크루 이름 중복 | 409 | `이미 사용 중인 값입니다.` |
| 중복 가입 | 409 | `이미 가입한 크루입니다.` |
| 정원 초과 | 409 | `크루 정원이 가득 찼습니다.` |
| 현재 인원보다 작은 최대 인원 | 409 | `현재 크루원 수보다 최대 인원을 작게 설정할 수 없습니다.` |
| 위임 대상 역할, 관리자 추방 등 상태 충돌 | 409 | `현재 크루 상태에서는 요청을 처리할 수 없습니다.` |
| 재시도 후에도 해소되지 않은 동시성 충돌 | 409 | `다른 요청과 충돌했습니다. 다시 시도해 주세요.` |
| 지원하지 않는 HTTP 메서드 | 405 | `지원하지 않는 요청 방식입니다.` |
| 지원하지 않는 미디어 타입 | 415 | `지원하지 않는 요청 형식입니다.` |
| 예상하지 못한 서버 오류 | 500 | `요청 처리 중 오류가 발생했습니다.` |

로그인 실패 메시지는 이메일 존재 여부를 구분하지 않는다. 잘못된 크루 비밀번호도 입력값이나
추가 크루 정보를 노출하지 않는다. 예상하지 못한 오류는 내부 예외 메시지를 그대로 반환하지
않는다.

## 4. 인증과 CSRF

- 회원가입과 로그인 전 `GET /api/v1/auth/csrf`로 토큰과 쿠키를 얻는다.
- POST, PATCH, DELETE는 `X-XSRF-TOKEN` 헤더에 현재 세션의 토큰을 보낸다.
- 로그인 성공 후 세션 고정 공격 방지를 위해 세션 ID가 변경될 수 있으므로 CSRF 토큰을 다시
  조회한다.
- 로그아웃은 현재 요청의 세션만 무효화한다.
- 회원탈퇴는 데이터 변경 커밋 후 해당 사용자의 모든 세션을 만료시킨다.
- 운영 세션 쿠키는 HTTPS에서 Secure, HttpOnly, SameSite 정책을 사용한다.

## 5. 목록과 공개 필드

- 기본 요청: `page=0`, `size=20`, `sort=id,desc`
- 허용 페이지 크기: 1~100
- 허용 정렬: `id,desc`, `id,asc`
- 빈 결과: 404가 아니라 200과 빈 `content`
- 크루 목록: 인증된 사용자만 조회
- 크루원 목록: 해당 크루의 `MANAGER`와 `MEMBER`만 조회

크루 페이지의 `data`는 다음 필드를 가진다.

```text
content, page, size, totalElements, totalPages
```

크루 항목은 `id`, `name`, `maxUsers`, `currentUsers`, `weeklyCertificationGoal`만 제공한다.
크루원 항목은 `userId`, `nickname`, `role`만 제공한다. 이메일과 모든 비밀번호 관련 값은
제공하지 않는다.

## 6. 수정 요청 규칙

- 닉네임을 현재 값과 같게 수정하면 변경 없는 성공 200을 반환한다.
- 크루 수정은 `name`, `password`, `maxUsers`, `weeklyCertificationGoal` 중 하나 이상을
  제공해야 한다.
- 크루 속성을 현재 값과 같게 수정해도 변경 없는 성공 200을 반환한다.
- 최대 인원은 잠금 후 확인한 현재 크루원 수보다 작게 설정할 수 없다.
- 요청에 계약에 없는 필드가 있으면 400을 반환한다.

## 7. 권한표

| 기능 | 비인증 | 인증·비소속 | MEMBER | MANAGER |
|------|--------|-------------|--------|---------|
| 회원가입·로그인 | 허용 | 허용 | 허용 | 허용 |
| 크루 목록 조회·가입 | 거부 | 허용 | 허용 | 허용 |
| 크루원 목록 조회 | 거부 | 거부 | 허용 | 허용 |
| 일반 크루 탈퇴 | 거부 | 거부 | 본인만 허용 | 해당 없음 |
| 크루 수정·삭제 | 거부 | 거부 | 거부 | 허용 |
| 관리자 위임·크루원 추방 | 거부 | 거부 | 거부 | 허용 |
| 관리자 크루 탈퇴 | 거부 | 거부 | 해당 없음 | 허용, 크루 삭제 |

사용자 본인의 닉네임 수정과 회원탈퇴는 인증된 본인에게만 허용한다.
